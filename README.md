# Production-Grade Chatbot API
# 🧠 Chatbot API – Event-Driven, AI-Native & GDPR-Compliant

A production-grade chatbot backend powered by FastAPI, vector search (Qdrant), OpenAI embeddings, Kafka event queues, MongoDB metadata, and optional WebSocket for real-time UX.

---

## 🚀 Features

- ✅ **AI-native semantic search** using OpenAI + Qdrant
- ✅ **Event-driven GDPR pipeline** (via Kafka)
- ✅ **MongoDB-backed message metadata**
- ✅ **Real-time chat** with WebSocket support
- ✅ **Async-first architecture** using FastAPI + Motor
- ✅ **Pluggable queue system** (Kafka/Redis/In-memory)
- ✅ Structured logging with `structlog`
